# History

Reports, audits and handoffs from earlier work on PeggyBank.

**These are a record, not instructions.** They describe what was true when they
were written, and several describe problems that have since been fixed. Nothing
here should be followed as current guidance — for that, read `CLAUDE.md` and the
documents in `docs/`.

They are kept because they explain *why* parts of the app are the way they are,
which is the one thing a git log does not tell you.
